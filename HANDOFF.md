# sbe-offers — передача в новое контекстное окно (2026-11-01, после выпуска 0.4.1)

Этот файл — точка входа для агента, который начинает работу со свежим контекстом.
Читается один раз и целиком; он короткий намеренно. Подробности — по ссылкам.

## Что за плагин

**LogicTEAM.КП** (`sbe-offers`) — коммерческие предложения для строительных
материалов. Менеджеры собирают КП в Telegram-боте, администратор настраивает
справочник и форму документа в плагине внутри Obsidian, на выходе — DOCX на
корпоративном бланке.

Вольт: `C:\Obsidian\mailers`. Папка плагина:
`.obsidian/plugins/sbe-offers`. Бэкенды живут **внутри** этой папки:
`offers-service/` (Go) и `offers-bot/` (Node).

## С чего начать в новой сессии

1. Прочитать `.obsidian/plugins/sbe-offers/AGENTS.md` (~430 строк) — это
   справочник: структура, правила, грабли, текущее состояние.
2. Прочитать этот файл до конца.
3. Загрузить навык `ub-mode` (правило проекта: в начале задачи и перед коммитом).
4. Только после этого — код. Разведку незнакомых участков отдавать дешёвой
   модели: `opencode run "<задача>" --dir "<каталог>" -m chad/deepseek-v4-flash`.

**Не читать целиком** `agents_arhiv.md` (4569 строк): история `sbe-offers`
теперь там, в разделе «История сессий». Ходить поиском по дате или по имени
функции, когда нужно понять, *почему* правило такое.

## Что в системе сейчас (кратко)

- **Материалы** — то, что продаём: свой SKU (назначает сервер), варианты ЕКН,
  вилка цен. **Цены в справочнике нет** — цена приходит из таблицы менеджера
  для конкретного КП. Материалы создаются из карточек Базы знаний с тегом
  `material`.
- **Системы** — карточки БЗ с тегом `commercial_propose` без `material`. Состав
  ссылается на материалы вики-ссылками `[[Название]]`. Своей цены нет.
  С 0.4.1 раздел показывает **кеш**; перечитать — кнопка «Перечитать из Базы
  знаний» (`POST /api/offers/systems/refresh`, admin).
- **Бот** — «Собрать КП» начинается с **контекста**: объект, назначение,
  площадь, адресат → сделка → системы → условия → и только потом позиции.
  Файл (таблица или описание) принимается на любом шаге. КП создаётся в начале
  разговора с номером и без позиций.
- **Форма КП** — блоки: текст, заголовок, список, таблица, **разрыв страницы**,
  **ссылки** из карточек, **текст по промту** (пишет модель, кэшируется),
  **картинка с обтеканием текстом**. У блока — отступы в пунктах, «с новой
  страницы», «не разрывать».

## Правила, которые нельзя нарушать

Полный список — в `sbe-offers/AGENTS.md`, раздел «Rules» и «Gotchas». Самые
дорогие грабли:

- `\b` в регулярках по кириллице **не работает** — границу задавать явно.
- Кириллица в собранном `main.js` — `\uXXXX` **верхним** регистром. Проверять
  только через `node scripts/check_bundle_strings.mjs`.
- Источники править только редактором. Перезапись через PowerShell-пайплайн
  превращает файл в мусор.
- Файлы писать UTF-8 **без BOM**. После правки проверять первые три байта.
- Время в API — `RFC3339Nano`; любая запись в БД двигает `updated_at`.
- Стенд собирать с `CGO_ENABLED=0`, иначе бинарь не запустится в alpine.
- Бинарь на стенде подменять **только** после сверки MD5 с сервером.
- **Экран не ходит в чужой сервис на каждый показ.** Читать из кеша, обновлять
  отдельной кнопкой (правило 2026-11-01: так выглядел живой 401 в «Системах»).
- **Межсервисному клиенту нужен повтор 401**, как и плагину.

## Что осталось несделанным (честный список)

1. **1284 строки состава систем без ссылок** — работа технолога, код её не
   лечит. Ровно столько было и до 0.4.0.
2. **SKU автосинхронизации бессмысленны** (`MAT-ПРОЧ-ОБЩ-NNNN`): синхронизация
   не передаёт подсказки типа и серии.
3. **Тексты блоков «по промту» никто не согласует** — в отличие от секций,
   которые менеджер принимает в чате.
4. **В редакторе формы нет предпросмотра** разрывов и обтекания.
5. **`sbe-kb/src/services/hash.ts`** — вторая копия общего
   `sbe-core/src/utils/files.ts`; свести при правке того плагина.
6. **Диалог бота вживую в Telegram** после выпуска человеком не прогонялся.
7. **`handleDraftText` (CC 13)** — диспетчер бота выше порога; разбирать при
   следующей правке бота таблицей обработчиков.
8. **Кеш «Систем» обновляется только кнопкой**: правка карточки в Базе знаний
   сама в раздел не приедет. Так задумано (требование пользователя), но помнить
   надо — жалоба «изменил карточку, а в системе старое» лечится кнопкой.

## С чего, скорее всего, продолжат

Пользователь ведёт работу малыми партиями и просит «фиксируй» по завершении.
Ближайшие естественные шаги: прогнать бота в Telegram вживую, согласовать
тексты блоков с человеком, добавить предпросмотр в редактор формы.

**Правило выпуска**: перед «выложи на самораздачу» обновлять этот файл вместе
с версией и хэшами — иначе новое контекстное окно начнёт с устаревших цифр
(так и случилось 2026-11-01: HANDOFF показывал 0.4.0 уже после выпуска 0.4.1).
